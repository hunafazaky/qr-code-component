### What I learned

The card's dimensions were kept flexible (`width: min(100%, 320px)` with a fluid image) instead of fixed pixel widths, so the layout still holds up cleanly below the 320px minimum the style guide calls for, without needing extra media queries.

### AI Collaboration

- Tool used: Claude
- How it was used: reviewed the finished solution for bugs and anti-patterns (missing attribution block, skipped heading level, non-fluid widths, unscoped color values, unused font weights), and reorganized the project into a flat file structure.
- What worked well: the color and spacing values already matched the style guide exactly, so the fixes were mostly structural rather than visual.
